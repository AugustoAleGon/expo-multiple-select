# expo-multiple-select

Simple multi-select component for expo. Inspired on react-native-multiple-select

## Installation


```sh
npm install expo-multiple-select
```


## Usage


```js
import { multiply } from 'expo-multiple-select';

// ...

const result = await multiply(3, 7);
```
